Política de Privacidade

1. Introdução

A privacidade do usuário é a prioridade absoluta do AuthX. Esta Política de Privacidade descreve de forma clara e objetiva como as informações são tratadas. O princípio fundamental do AuthX é a proteção máxima de dados por meio do isolamento: todas as informações permanecem exclusivamente no dispositivo do usuário.

2. Coleta de Dados (Zero Data Collection)

O AuthX opera sob uma arquitetura estritamente offline.

  • Não coletamos, não transmitimos e não armazenamos dados pessoais, senhas, tokens ou chaves de autenticação em servidores externos.
  • Não utilizamos cookies, rastreadores, ferramentas de análise (analytics) ou qualquer tecnologia de monitoramento de terceiros.

3. Armazenamento de Dados

Todos os dados inseridos ou gerados pelo AuthX, incluindo chaves de autenticação de dois fatores, são armazenados exclusivamente na memória interna do dispositivo do usuário.

O Desenvolvedor não possui acesso técnico aos dados armazenados. Em caso de perda do dispositivo ou desinstalação do aplicativo sem a realização de backup prévio, não será possível recuperar as informações, garantindo que somente o próprio usuário tenha acesso a elas.

4. Segurança

O AuthX foi projetado seguindo os melhores padrões de design e eficiência de código, utilizando os mecanismos de segurança disponibilizados pelo sistema operacional para proteger os dados locais e impedir o acesso por aplicativos maliciosos.

5. Compartilhamento com Terceiros

O AuthX não realiza comunicação com a internet para fins de transmissão de dados. Dessa forma, não há compartilhamento de informações com terceiros, incluindo anunciantes, parceiros comerciais, autoridades governamentais ou quaisquer outras entidades.

6. Alterações nesta Política

Esta Política de Privacidade poderá ser atualizada caso ocorram alterações futuras no aplicativo que impactem o processamento de dados. Ainda assim, o compromisso com a funcionalidade offline e com a privacidade máxima do usuário permanecerá inalterado.
